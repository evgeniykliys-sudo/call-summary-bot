# call-summary-bot

Telegram-бот: присылаете запись созвона или планёрки — получаете выжимку (решения, задачи
с ответственными и сроками, открытые вопросы) и полную расшифровку с разметкой, кто говорит.

Распознавание речи и разметка говорящих работают **локально на CPU** — запись не уходит в сторонние
сервисы распознавания. В Claude отправляется только текст расшифровки для выжимки.

## Пример
Тестовая планёрка (3 участника, 1,5 минуты, `scripts/test_meeting.mp3`) → бот вернул:
```
👥 Участники: Спикер 1, Спикер 2 — Дмитрий, Спикер 3
✅ Решения
1. Запускаем бота до 20 октября
2. Предоплату через бота не берём
3. Напоминания пациентам за день до визита обязательны
4. Бюджет на рекламу на первый месяц — 30 тысяч рублей
📌 Задачи
• Подключить напоминание за день до визита — Дмитрий (Спикер 2), срок: до пятницы
• Подготовить тексты для меню бота — Спикер 3, срок: до среды
• Согласовать цены с бухгалтерией и переслать Дмитрию — Спикер 1, срок: до понедельника
❓ Открытые вопросы
• Записывать к конкретному врачу или в любое свободное окно
```
Все решения, задачи и сроки совпали с заложенными в сценарий (`scripts/expected.md`). Имена Спикера 1 и 3
в разговоре не звучали — бот их честно не угадывает.

## Запуск
```bash
python -m venv venv
venv\Scripts\pip install -r requirements.txt
python download_models.py      # модели разметки говорящих, ~46 МБ
copy .env.example .env         # BOT_TOKEN, ANTHROPIC_API_KEY, ALLOWED_USER_IDS
python bot.py
```
Модель Whisper (~480 МБ) скачается сама при первой записи.

Без Telegram, для больших файлов:
```bash
python cli.py запись.mp3       # рядом сохранит .transcript.txt и .summary.txt
```

## Ограничения
- Telegram даёт ботам скачивать файлы только **до 20 МБ** (час разговора в mp3 64 кбит/с ≈ 28 МБ):
  длинную запись — сжать/разделить или прогнать через `cli.py`.
- Скорость на CPU — около минуты обработки на минуту записи (распознавание + разметка говорящих).
- Разметка говорящих ошибается на коротких репликах похожих голосов; имена определяются только
  по обращениям в самом разговоре.

## Тесты
- `scripts/make_test_meeting.py` — синтезирует планёрку тремя голосами (Edge TTS) с заранее известными
  решениями и задачами (`scripts/expected.md`) — проверка не «на глаз», а по списку.
- `scripts/calibrate_diarization.py` — подбор порога разметки говорящих на тестовой записи.
